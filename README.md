# Mehmetcik

### Cyber Threat Intelligence | IOC Collection | Malware | C2 Infrastructure

**Mehmetcik** is an open-source Cyber Threat Intelligence (CTI) collection repository focused on gathering, organizing, and sharing Indicators of Compromise (IOCs), malware-related intelligence, and Command & Control (C2) infrastructure.

This repository serves as a centralized collection of threat intelligence data gathered from various public sources, security research platforms, and independent investigations.

## Repository Contents

- **IOCs:** IP addresses, domains, URLs, file hashes, and other Indicators of Compromise.
- **Malware:** Malware samples metadata, hashes, family classifications, and related intelligence.
- **C2 Infrastructure:** Identified Command & Control servers, domains, IP addresses, and associated infrastructure.
- **Threat Intelligence:** Collected information, technical observations, and references related to malicious activities.

## Data Sources

Intelligence may be collected and correlated from publicly available sources, including:

- VirusTotal
- ANY.RUN
- Triage
- MalwareBazaar
- URLhaus
- ThreatFox
- Other publicly available threat intelligence platforms

All collected data is subject to source availability and verification.

## Disclaimer

This repository is intended for cybersecurity research, threat intelligence analysis, and defensive security purposes only.

The collected indicators may contain malicious URLs, IP addresses, domains, file hashes, and other potentially harmful artifacts.

**Do not interact with or execute potentially malicious artifacts on production systems.**

The repository maintainer is not responsible for any misuse of the information provided.
